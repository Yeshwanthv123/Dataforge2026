## Code and model

The memory mechanism and decoder implementation are project-original, AI-assisted Python. The app does not import BDH code, use BDH/BDH-CQ pretrained weights, call their services or claim to reproduce either complete architecture. Package reuse is listed in THIRD_PARTY.md and the dependency inventories. The public worker executes the same model.py as the Docker backend. The UI animates computed states, not invented experimental outputs.

## Data and weights

All 7,500 samples are synthetic numeric vectors generated by backend/app/model.py with seed 42: 6,000 training and 1,500 held-out samples. No scraped records, personal data, external datasets or downloaded pretrained weights were used. The trained decoder.npz, synthetic_dataset.npz and metrics.json are distributed. Symbol labels are arbitrary teaching labels. The 99.933% result is symbol-decoder classification accuracy only.
