# Sources, licenses and AI assistance

## Original work

TRACE application code, original explanatory text, synthetic data generator and trained decoder artifacts were created for this project with Codex AI assistance. The team should disclose this assistance, review the work and take responsibility for what it presents. No third-party BDH source code or pretrained weights are incorporated. Original source in this folder is MIT-licensed.

Organizer-provided problem statements remain private reference files and are excluded from the public source and submission ZIP. They are not relicensed by this project.

Exact source URLs, versions, hashes where available, license declarations and collected notice paths are recorded in [DEPENDENCIES.json](DEPENDENCIES.json). Notices are retained under licenses/npm, licenses/python, licenses/public-runtime and licenses/runtimes. frontend/package-lock.json also records platform-optional build packages; only installed packages have local notice copies. npm ci retrieves each platform's original package notices. Docker base images retain their upstream distribution notices; their OS packages are not copied into the source ZIP. Docker tags are python:3.12-slim, node:22-alpine and nginx:1.28-alpine; tags can receive upstream updates.

Public runtime binaries are unmodified Pyodide 0.27.7 release files and wheels, pinned by SHA-256 in PUBLIC_RUNTIME_LOCK.json. Corresponding Pyodide source and build instructions are at https://github.com/pyodide/pyodide/tree/0.27.7. Its MPL license and CPython/Emscripten notices are included. Package sources are identified by exact version in DEPENDENCIES.json and the upstream Pyodide package recipes. NumPy wheels retain bundled-library notices. Third-party licenses take precedence over the project MIT license for their components.

Fonts are system fonts: Inter if installed, Segoe UI/Arial fallbacks, Georgia for equations, and Consolas/monospace for numeric labels. The presentation references Helvetica Neue; PDFs use standard Helvetica. No font binaries are distributed. No tracking script or font CDN is used. The geometric brand and charts are original CSS/SVG; icon glyphs are Lucide.

## Data, model, images and presentation

Original synthetic dataset and trained decoder are included under the project MIT license to the extent applicable rights. They were generated by backend/app/model.py, not downloaded. See MODEL_CARD.md and AI_DISCLOSURE.md. No external pretrained weights or personal data are used.

ASSET_REGISTER.json records source, license scope and SHA-256 for data, weights, brand SVG and three pitch images. The cover and architecture images were AI-generated for this project; the prototype image is a user-provided screenshot of TRACE. The architecture image depicts the Docker edition. These illustrative images do not serve as empirical evidence.

The pitch layout was adapted from the bundled Codex Simple Dark Mode reference. The original reference deck, original photographs and embedded font binaries are not redistributed. The resulting project-specific deck, text and original assets accompany this submission; any third-party elements retain their underlying rights. No proprietary BDH diagram was copied.
